# Syncria v0.5.2 — Easier for everyone

Syncria should help you keep your files together, even if you have never used a NAS before. This update makes the screens, instructions, and buttons much easier to understand.

## What's different?

**A simpler Home screen.** It now shows three things to do first: connect your files, add your NAS box, and set up your first sync. There's also a short guide that explains unfamiliar words.

**An easier setup.** Instead of asking you about “sources,” “destinations,” and “bidirectional relationships,” Syncria asks:

1. Where are your files now?
2. Where should copies go?
3. How should the sync work?
4. Do these choices look right?

The normal options are already selected. Your new sync still starts turned **off**, so it cannot begin copying files before you turn it on.

**Clearer choices for keeping two NAS boxes matched.** You can choose “one way” or “both ways.” If both boxes have different copies of the same file, Syncria explains its five existing choices in ordinary words.

**Less confusing deletion settings.** Syncria explains that deleting a file can also delete matching copies, and that the default 10-minute Undo window can help recover a mistake.

**Friendlier account, NAS, and activity screens.** Labels now say what information to enter and what the buttons actually do. Technical sign-in fields are identified as advanced settings.

**Better help on GitHub.** The README and [Getting Started](GETTING-STARTED.md) now explain the everyday workflow first. The old technical documentation and earlier release details are still available in [Technical reference](TECHNICAL.md).

## What stayed the same?

This is a **usability update**, not a new syncing engine. Your saved cloud accounts, NAS boxes, folders, syncs, schedules, one-way and both-way choices, the five conflict policies, deletion settings, and in-app updater are still there.

Syncria still does **not** store copies of your files on the machine running Syncria. Your files remain on the selected NAS or cloud service.

## How to install the update

Inside Syncria, open **App Updates**, select **Check again**, then **Download & install update**. You can watch the real update progress from there. No extra updater container or manual compilation is needed.

If your current version uses a different name for the Updates screen, open **Updates** instead.

## Important reminder

Syncing is not the same as having a separate backup. Keep an independent backup of any family photos, documents, or other files you cannot replace.

For advanced deployment and troubleshooting, see [Technical reference](TECHNICAL.md).
