# Syncria v0.6.3 — a more balanced interface

This release brings some personality back to Syncria without returning to the oversized graphics and high-contrast styling of earlier versions.

- A warmer, lightly blue-tinted navigation area with clearer active-page styling.
- More distinctive Overview metrics, including small symbols and subtle status accents.
- A useful Overview introduction without a full-screen promotional hero.
- More readable setup steps and empty states.
- Better visual grouping for NAS devices, cloud accounts and sync results.
- Consistent styling for transfer activity, the built-in updater, settings and the sync wizard.
- Responsive layout and reduced-motion preferences are retained.
- Tailwind is compiled into the Go binary; no CDN or separate frontend service is required.

This is a visual update. Your sync settings, credentials, NAS shares, transfers, conflict handling, and deletion recovery are preserved.

The built-in updater installs the signed-off binaries after tests and SHA256 verification during release publishing.
