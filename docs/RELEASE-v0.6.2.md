# Syncria v0.6.2

A more considered interface for everyday file synchronization.

## Changes

- Stronger typographic hierarchy, more consistent spacing, and carefully aligned controls across Syncria.
- Removed duplicate page headings and the oversized Overview introduction.
- Improved Overview statistics, first-run setup instructions, and empty states.
- Refined the NAS list, cloud account sections, activity summaries, update details, and settings.
- Improved responsive spacing and navigation for smaller screens.
- Success notifications can be dismissed and no longer follow you through each view.
- Tailwind CSS remains built into the application, with no runtime CDN or separate service.

## Preserved functionality

Existing sync relationships, Google Drive and Dropbox accounts, NAS connections, conflict resolution, deletion recovery, and in-app updates are unchanged.

The release workflow runs compilation, tests, cross-platform builds, and checksum verification before publishing the updater assets.
